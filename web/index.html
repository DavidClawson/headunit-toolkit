Advanced — Device settings · clock, brightness, Bluetooth name, region · no firmware flash

Change safe settings — clock format, brightness, Bluetooth name, startup volume, radio region — by loading the Config.ini your unit exports, then re-importing it. This never touches the firmware image, and the unit just reboots to apply.

How to export & import your Config.ini (on the unit)

⚠️ Use a FAT32 USB stick with no Update folder on it. If an Update folder is present, the unit tries to flash firmware instead. An empty stick is ideal — it'll just say “No music found,” which is fine.

  1. Insert the stick, then press Home. (Plugging it in jumps to the music player / “No music file” — Home gets you back to the home screen.)
  2. Open Settings → Factory Set, enter 666999, and press Enter.
  3. Open Configure Setting and scroll all the way down — you'll see three buttons: Save, Export, and Import config file.
  4. Tap Export config file — it writes Config.ini to the stick.
  5. Load that file below, change what you want, and Download it.
  6. Copy the downloaded file back onto the stick, return to this screen, and tap Import config file. The unit reboots with your changes.
